Entry for the Make.fun contest "The Comment Above the Code": one developer comment, written as if left above fragile legacy checkout code.

## Run

    python3 main.py

This writes a single line to `output/entry.txt` (or to `MAKEFUN_OUTPUT_DIR` when set), with no trailing newline.

## Entry

    // Checkout works because the warehouse clock is 11 minutes slow. Fix NTP and orders ship yesterday.
